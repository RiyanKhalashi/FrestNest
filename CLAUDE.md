# FreshNest — university final year project

Agricultural marketplace website connecting Farmer, Dealer, Transport Provider and Admin (Bangladesh).

- All agreed design decisions: `docs/decisions/` (one file per topic; start with `fyp-project-overview.md` and `fyp-prototype-plan.md`).
- Clickable prototype: `docs/prototype/` — `farmer.html` done, `dealer.html` built, `transporter.html` built (own `css/transporter.css`), `admin.html` built (awaiting review, own `css/admin.css`); shared styles in `css/base.css`.
- Real app (building since 2026-11-17): `backend/` (Express + Prisma) and `frontend/` (Next.js); see `README.md` and `docs/decisions/fyp-build-progress.md`. Run with `npm run dev`. Node lives in `~/.local/node/bin` (add to PATH in tool shells).
- Way of working: the user shares ideas in small steps; suggest improvements, agree each part, then record it in `docs/decisions/` and memory. Do not build until the user says to build.
- The user may write in Bangla/Banglish; reply in English.
- Save tokens: keep replies focused; read only the parts of files you need.
