The user (university student, DIU) is building a website for their final year project. They share the idea in small steps. For each step: listen to their thought, suggest improvements as their developer, discuss until both agree, then save the finalized decision to memory (one memory per finalized part, linked to [[fyp-project-overview]]).

**Why:** They want to stay in control of the design and make sure every portion is mutually agreed before moving on.

The user may write in Bangla (Banglish); treat it as English and reply/document in English.

**How to apply:** Don't jump ahead or write code before a portion is agreed. After each idea: restate it, give concrete improvements/questions, wait for confirmation, then record the final version.
