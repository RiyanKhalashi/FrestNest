**How it is built**
- Text lives in `docs/report/chapters/*.md`; title, names, ID and supervisor live in `docs/report/report.json`; the cover and declaration wording lives in `docs/report/front.mjs`.
- `docs/report/build.mjs` (npm `docx` pinned to 9.15.3, standalone package in `docs/report/`) writes `docs/report/FreshNest-Project-Report.docx`. Run `npm run build` there.
- Layout follows the DIU demo report (`Demo Project Doc.pdf`): A4, Times New Roman 12 pt, 1.5 spacing, footer "©Daffodil International University" with the page number, roman numbers for the front matter, DIU logo on the cover (`assets/diu-logo.png`, taken from the demo PDF).
- Front matter order: cover, supervisor's declaration, student's declaration, acknowledgements, abstract, table of contents, list of figures (the approval page was removed on the user's request).
- `[[...]]` in the text shows as a yellow placeholder. Figures in `diagrams/` or `screenshots/` are inserted automatically once the PNG exists (Chapter 1 needs `block-diagram.png` and `gantt-chart.png`).
- Edit the Markdown, never the .docx, until the final polish: every build replaces it.
- The Mac has no Word, Pages or LibreOffice, and VS Code can't show .docx files. For review, `npm run preview` (playwright-core 1.49.0 with the installed Google Chrome) writes `FreshNest-Report-Preview.pdf`: the cover, the front pages (i, ii, ...) and Chapter 1 to the references (1, 2, ...), printed as three parts and joined with pdf-lib 1.17.1. Since 2026-11-27 it also has the TABLE OF CONTENTS, LIST OF FIGURES and LIST OF TABLES (after the abstract, roman pages, in the batchmate's layout with dotted leaders). The chapters are printed first, every heading and caption is found in that PDF with pdfjs-dist 4.10.38 (lines matched in document order), and the front part is printed again until its own roman numbers settle. All 158 numbers were checked against the real pages. The PDF can now be submitted without Word. Open it with `open` so it shows in Preview. Both outputs share `markdown.mjs` and `front.mjs`. Added 2026-11-26 after the user couldn't see Chapter 1 in VS Code.
