Four roles, four personalities, one marketplace

Each role keeps the same logo, fonts, page layout and meaning colors (green means good, red means a problem). What changes is the palette, the density and one local motif that matches how that person works.

Shared touches, all roles

The human and agri layer that ties the four looks together

Kantha stitch

Running-stitch lines from nakshi kantha quilts replace plain rules under section titles. Each role tints them in its own colors.

Hand-drawn line art

Slightly uneven strokes and soft fills, like a sketch in a field notebook. Same set for every role.

Seasonal banner

The home banner follows the real season, so the site looks different in December than in July.
